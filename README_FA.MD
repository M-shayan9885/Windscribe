# جستجوگر خودکار لوکیشن ویندسکرایب (WALF)

برنامه **WALF** یک ابزار پیشرفته، کاملاً خودکار و هوشمند برای بنچمارک شبکه‌ و کشف جامع نودهای VPN است که از یک رابط کاربری مدرن گرافیکی (GUI) ساخته شده با CustomTkinter بهره می‌برد. این برنامه به عنوان یک موتور اتوماسیون قدرتمند برای نسخه خط فرمان بومی `windscribe-cli` عمل می‌کند و با **جستجو، اسکن و تست سیستماتیک تک‌تک سرورها، شهرها و موقعیت‌های جغرافیایی در کل شبکه جهانی ویندسکرایب**، فرآیند خسته‌کننده تعویض دستی سرورها را کاملاً حذف می‌کند.

به جای حدس زدن اینکه کدام نود کار می‌کند، WALF کل این فرآیند سنگین را از طریق پایش خودکار و بدون نیاز به نظارت شبکه انجام می‌دهد. این ابزار به صورت پیاپی یا تصادفی تمام قاره‌ها، کشورها و سرورها را پشت سر هم روی پروتکل‌ها و پورت‌های مختلف زیر ذره‌بین قرار می‌دهد تا دقیقاً مسیرهایی که بهترین عملکرد و اتصال را دارند پیدا کند.

چه به دنبال کاهش پینگ (Latency)، تست پهنای باند و سرعت دانلود باشید، و چه به دنبال **دور زدن کامل فایروال‌های سخت‌گیرانه و سانسور شدید اینترنت**، WALF تمام مسیرهای کشف نود را خودکار کرده و وضعیت سلامت هر لوکیشن را در یک دیتابیس محلی ذخیره می‌کند.

## 🚀 قابلیت‌های کلیدی

* **پایش همزمان پورت‌ها و پروتکل‌ها:** تست خودکار ترکیب‌های مختلف اتصال روی WireGuard ،IKEv2 ،UDP ،TCP ،Stealth و WStunnel؛ کاربر می‌تواند علاوه بر پورت‌های پیش‌فرض، برای هر پروتکل پورت دلخواه اضافه یا حذف کند.
* **همگام‌سازی پورت‌ها با کلاینت نصب‌شده:** فهرست پورت‌های هر پروتکل را با دستور رسمی `windscribe-cli ports` از کلاینت Windscribe به‌روز می‌کند.
* **گزینهٔ Anti-Censorship:** با فعال‌کردن این گزینه، اسکن فقط از پروتکل‌های Stealth و WStunnel و پورت‌های فعال آن‌ها استفاده می‌کند؛ با غیرفعال‌کردن آن، پروتکل‌های انتخاب‌شدهٔ کاربر طبق تنظیمات عادی اسکن می‌شوند. این گزینه در تنظیمات و پروفایل ذخیره می‌شود و ترفندهای داخلی Anti-Censorship کلاینت Windscribe را فعال نمی‌کند.
* **فیلتر کردن دقیق لوکیشن‌ها:** کشور، شهر و سرور در فهرست‌های جستجوپذیر و قابل اسکرول با چرخ ماوس انتخاب می‌شوند. کشورها همراه پرچم نمایش داده می‌شوند و فهرست شهرها و سرورها بر اساس انتخاب‌های قبلی محدود می‌شود.
* **بنچمارک لحظه‌ای عملکرد:** ادغام کامل با APIهای Speedtest جهت سنجش پینگ (Ping)، سرعت دانلود و سرعت آپلود به صورت زنده در داشبورد برنامه.
* **بهینه‌سازی اجرای تست:** اطلاعات مکان‌ها یک‌بار بارگذاری می‌شود، ادامهٔ تست نتایج قبلی را یک‌جا بررسی می‌کند و وقتی سنجش سرعت خاموش است Speedtest اجرا نمی‌شود. لاگ‌های روی صفحه نیز در اجرای طولانی محدود می‌شوند تا رابط کاربری روان بماند؛ نتایج کامل همچنان در دیتابیس حفظ می‌شوند.
* **استراتژی‌های پیشرفته اجرا:**
    * *Randomize Cities:* جابه‌جا کردن و شافل کردن لوکیشن‌های جغرافیایی انتخابی در عین حفظ ترتیب پروتکل‌های تعیین‌شده.
    * *Chaos Mode (حالت آشوب):* شافل کردن کل صف به صورت کاملاً تصادفی و تست پیاپی کانفیگ‌های رندوم از سرورها، پورت‌ها و پروتکل‌ها.
    * *Stop on Success:* توقف آنی فرآیند تست به محض پیدا شدن اولین اتصال سالم و موفق (ایده‌آل برای دور زدن سریع سانسور اینترنت).
* **مدیریت پروفایل و ذخیره پیکربندی:** امکان ذخیره تنظیمات و پارامترهای مختلف اسکن در قالب پروفایل‌های مجزا جهت بارگذاری سریع در آینده.
* **لاگ‌نویسی قدرتمند و پایگاه داده SQLite:** ذخیره نتایج تمام تست‌ها در یک دیتابیس محلی (`windscribe_results.db`) به همراه یک رابط کاربری تمیز برای فیلتر کردن لاگ‌ها و خروجی گرفتن از گزارش‌ها به صورت فایل CSV. پس از پایان تست، برنامه می‌تواند برای ذخیره گزارش در مسیر دلخواه از شما سؤال کند.
* **پشتیبانی از فایل اجرایی مستقل:** سازگاری کامل با محیط‌های کامپایل شده جهت هدایت درست جریان‌های headless هنگام خروجی گرفتن به صورت کامپایل تک‌فایله.

## 🛠️ پیش‌نیازها

قبل از اجرای برنامه WALF، مطمئن شوید سیستم شما شرایط زیر را دارد:

۱. **کلاینت دسکتاپ Windscribe** باید نصب بوده و ابزار خط فرمان آن (CLI) فعال باشد:
   * **ویندوز:** نصب در مسیر پیش‌فرض `C:\Program Files\Windscribe\windscribe-cli.exe`.
   * **لینوکس / مک:** مطمئن شوید دستور `windscribe-cli` در لوکیشن محیطی `$PATH` سیستم شما تعریف شده و قابل دسترسی است.
۲. قبل از شروع اسکن‌های خودکار، مطمئن شوید که از طریق نرم‌افزار دسکتاپ یا ترمینال وارد اکانت ویندسکرایب خود شده‌اید (اکانت باید لاگین باشد).
۳. *(فقط در صورت اجرا از سورس کد)* **پایتون 3.10+** باید روی سیستم و توابع محیطی شما نصب و پیکربندی شده باشد. برای سازگاری به‌روز، پایتون 3.12 توصیه می‌شود.

## 📦 دانلود و نصب

### گزینه ۱: راه‌اندازی سریع (پیشنهاد شده برای کاربران ویندوز)
بدون نیاز به نصب پایتون یا ابزارهای جانبی:
۱. فایل `WALF.exe` را طبق دستورهای پایین از سورس بسازید یا پس از انتشار نسخهٔ آماده، آن را از بخش Releases دریافت کنید.
۲. فایل اجرایی را در یک پوشه با دسترسی نوشتن قرار دهید.
۳. روی `WALF.exe` دوبار کلیک کنید. فایل داده مکان‌ها داخل برنامه قرار دارد؛ تنظیمات، نتایج دیتابیس و گزارش‌ها کنار فایل اجرایی ذخیره می‌شوند.

### گزینه ۲: اجرا از طریق سورس کد پایتون
اگر ترجیح می‌دهید کد را به صورت دستی اجرا، ویرایش یا بازرسی کنید، ریپازیتوری را کلون کرده و وابستگی‌ها را با استفاده از فایل `requirements.txt` نصب کنید:

```bash
# کلون کردن پروژه
git clone https://github.com/M-shayan9885/Windscribe.git
cd Windscribe

# نصب پکیج‌های پایتون از روی فایل requirements.txt
pip install -r requirements.txt
```

### ساخت فایل اجرایی ویندوز
در ویندوز، وابستگی‌های ساخت را نصب و فایل `build_exe.bat` را اجرا کنید. فایل تک‌اجرایی در مسیر `dist\WALF.exe` ساخته می‌شود:

```bat
python -m pip install -r requirements-build.txt
build_exe.bat
```

فایل اجرایی شامل داده‌های مکان و وابستگی‌های پایتون است؛ اما برای اتصال، کلاینت Windscribe و CLI آن باید روی سیستم نصب و وارد حساب شده باشند.

### اجرای نسخهٔ دستی در Termux (اندروید)
نسخهٔ Termux محیط متنی دارد. اندروید CLI دسکتاپ Windscribe را در اختیار Termux نمی‌گذارد؛ بنابراین سرورها را خودتان در اپ Windscribe عوض کنید. WALF تأیید شما را ثبت می‌کند و سپس می‌تواند سرعت اتصال فعلی را با Speedtest بسنجد.

```sh
pkg update
pkg install python git
git clone https://github.com/M-shayan9885/Windscribe.git
cd Windscribe
python -m pip install -r requirements-termux.txt
python termux_walf.py
```

Termux وضعیت اتصال یا پروتکل/پورت اپ اندروید را کنترل یا تأیید نمی‌کند. پروتکل به‌صورت برچسبی که شما وارد می‌کنید ذخیره می‌شود و پورت برای گزارش اختیاری است. اگر نام سرور در اپ اندروید متفاوت است، همان نام را هنگام ثبت وارد کنید. مدت ذخیره‌شده شامل جابه‌جایی دستی بین اپ‌ها و تأیید شماست و زمان اتصال خودکار VPN نیست. دیتابیس و گزارش‌ها در `~/.walf/` ذخیره می‌شوند.
